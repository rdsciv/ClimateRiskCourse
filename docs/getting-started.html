Get started

About 30 minutes to a working environment and your first Grok session on the engagement.

Requirements

  • Grok Build CLI authenticated
  • uv (install below if needed)
  • Git

0. Install uv (once per machine)

If uv is not already on your PATH:

curl -LsSf https://astral.sh/uv/install.sh | sh

Then open a new terminal (or follow the installer’s PATH note) and check:

uv --version

1. Clone the course

Copy these two lines exactly. The first downloads the repo; the second moves you into it.

git clone https://github.com/rdsciv/ClimateRiskCourse.git
cd ClimateRiskCourse

2. Install dependencies with uv

uv sync

That creates a project environment and installs everything from pyproject.toml. Use uv run for every script below — do not call system python3 or pip.

3. Seed clients and pick a track

uv run scripts/seed_all_clients.py
uv run scripts/set_track.py colorado   # or kerrville | datacenter
uv run scripts/course_lint.py

4. Open Grok Build

Start Grok in the ClimateRiskCourse folder (repo root). Root AGENTS.md loads automatically. Ask:

Summarize firm/methodology.md in five bullets.
Do not open any exercises/**/solution/ folders.

5. Orientation

Work through exercises/00-orientation/, then week 1.

  • Read explainer variants first
  • Complete problem with Grok
  • Open solution only after an honest attempt
  • Write outputs to clients/<track>/outputs/week-N/

Epistemic rules

  1. Computed figures come from saved scripts run with uv run.
  2. Judged figures carry mechanism + precedent + the word judgment.
  3. Never invent government/vendor data pulls.
  4. Document gaps; do not fill them silently.
  5. Do not sum losses across scenarios.

Reference pipelines (optional)

uv run scripts/reference_week1_overview.py
uv run scripts/reference_week3_score.py
uv run scripts/reference_week4_scenarios.py
These references show a clean path — attempt problems yourself before relying on them.
