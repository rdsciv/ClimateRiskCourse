## The engagement

You operate as a consultant. Each week's deliverable becomes next week's input. Capstone: **judgment** for the board and a **record** for regulators / grant / EIS reviewers.

## Three tracks, one method

| Track | Folder | Decision language |
|-------|--------|-------------------|
| Redrock Basin Authority | `clients/colorado-river-reservoirs` | Releases, allocations, hydropower |
| City of Kerrville | `clients/kerrville-flood` | Mitigation, access, buyout vs defend |
| Horizon Grid LLC | `clients/texas-datacenter-eis` | EIS alternatives, water, grid |

Pick one. Stay with it through week 6.

## Tooling

| Layer | Role |
|-------|------|
| **Grok Build** | Orchestrates the engagement |
| **uv** | Environment + `uv run` for all scripts |
| **`firm/`** | Methodology, scenarios, anchors |
| **`clients/<track>/`** | Book, docs, outputs |

## Weekly rhythm

- **Monday pattern** — methodology against the live environment
- **Mid-week** — 3–4 hours of build time
- **Friday** — demo the deliverable

Self-paced: treat each section as a week. Do not skip the audit trail.
