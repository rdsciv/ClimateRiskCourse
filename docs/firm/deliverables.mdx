Every weekly output should be client-sendable in form, even when draft.

## Shared requirements

1. Title, client name, date, simulated-data banner
2. Decision question answered up front
3. Methods note: computed vs judged
4. Data provenance + gaps
5. Next-step dependencies

## Week filenames

| Week | Pattern |
|------|---------|
| 1 | `week-1/framing_and_delivery_plan.md` |
| 2 | `week-2/mapped_portfolio.md` + `hypothesis_register.md` |
| 3 | `week-3/hazard_dataset_readme.md` + tables |
| 4 | `week-4/scenario_results.md` |
| 5 | `week-5/portfolio_synthesis.md` |
| 6 | `week-6/board_presentation.md` + `regulatory_submission.md` |

Templates: `templates/board-presentation/` and `templates/regulatory-submission/`.
