---
title: "QA protocols"
description: "Re-run, lineage, label, gap, and scenario tests."
---

Before any number ships:

1. **Re-run** — cold session re-executes the script and matches
2. **Lineage** — figure → script + inputs + anchor or judgment note
3. **Label** — judged figures say **judgment**
4. **Gap** — unknowns listed, not smoothed
5. **Scenario** — alternatives, not additive

Week 6: open a **fresh** Grok session to QA the deliverable. Authoring sessions are biased.
