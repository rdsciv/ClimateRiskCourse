## Severity bands

| Severity | Description | Indicative impact |
|----------|-------------|-------------------|
| S0 | Nuisance | 0–2% |
| S1 | Moderate, days–weeks | 5–15% |
| S2 | Major, months / multi-season | 20–40% |
| S3 | Severe / service failure | 50–80% |

## Track applications

- **Colorado:** allocation cuts, hydropower derate, compact-sensitive delivery stress
- **Kerrville:** replacement at risk, critical-facility continuity, buyout vs defend
- **Datacenter:** water/power alternatives become material in EIS; go/no-go input
