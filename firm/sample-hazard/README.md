# Sample hazard grids

Offline training stand-in for county-level physical risk scores (0–10).

- **source:** `firm_sample_grid`
- **version:** `v1`
- **not** a government product — do not label as FEMA/NRI/NOAA output

Week 3 teaches joining these scores to geocoded assets and logging the pull as a sample-grid load. Optional live APIs may replace this slot if configured; provenance must change accordingly.
