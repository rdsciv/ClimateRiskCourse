# Deliverable standards

Every weekly output should be **client-sendable in form**, even when content is still draft.

## Shared requirements

1. Title, client name, date, simulated-data banner
2. Decision question answered in the first screen/page
3. Methods note: computed vs judged
4. Data provenance + gaps
5. Next-step dependencies (what this unlocks next week)

## Week-specific shapes

| Week | Filename pattern | Must include |
|------|------------------|--------------|
| 1 | `week-1/framing_and_delivery_plan.md` | Scope, out-of-scope, milestones, risks |
| 2 | `week-2/mapped_portfolio.md` + `hypothesis_register.md` | Geo/sector views, escalation list, hypotheses |
| 3 | `week-3/hazard_dataset_readme.md` + tables | Join keys, scores, audit log pointer |
| 4 | `week-4/scenario_results.md` | Standard set + 2–3 bespoke; no cross-sum |
| 5 | `week-5/portfolio_synthesis.md` | Concentration, priorities, pricing language, recs |
| 6 | `week-6/board_presentation.html` + `regulatory_submission.md` | Judgment vs record split |

## Tone

- Direct, executive-ready prose
- No hype about AI
- Prefer tables for numbers; prose for judgment
